# truck-weather

##Project Description
A simple weather application that retrieves current weather information using the Open-Meteo API.

##Features
Fetches current weather data.
Displays temperature in Celsius.
Displays wind speed in km/h.
Displays relative humidity.
Displays local date and time.
Uses the user’s local timezone.

##Technologies Used
HTML
JavaScript
Open-Meteo API
VS Code

##API
This project uses the Open-Meteo Forecast API.

##How to Use
Open the project in VS Code.
Run the index.html file using Live Server.
Click the “Check the weather” button.
View the current weather information.

##Timezone Update
The API uses timezone=auto to retrieve the local timezone based on the coordinates.
